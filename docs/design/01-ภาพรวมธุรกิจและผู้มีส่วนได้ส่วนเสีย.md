# 1. ภาพรวมธุรกิจและผู้มีส่วนได้ส่วนเสีย

## 1.1 บริบทการดำเนินงานของสหกรณ์ออมทรัพย์ครู

สหกรณ์ออมทรัพย์ครู เป็นนิติบุคคลที่จัดตั้งและดำเนินงานภายใต้ **พระราชบัญญัติสหกรณ์** โดยมีนายทะเบียนสหกรณ์ (กรมส่งเสริมสหกรณ์) กำกับดูแล และมีกรมตรวจบัญชีสหกรณ์ตรวจสอบงบการเงิน โครงสร้างการกำกับดูแลหลักประกอบด้วย:

- **คณะกรรมการดำเนินการ** — มาจากการเลือกตั้งของสมาชิกในที่ประชุมใหญ่ กำหนดนโยบาย อนุมัติวงเงินกู้รายใหญ่ กำกับการดำเนินงาน
- **ผู้ตรวจสอบกิจการ** — ตรวจสอบการดำเนินงานและการเงินภายใน รายงานต่อที่ประชุมใหญ่
- **ฝ่ายจัดการ/เจ้าหน้าที่สหกรณ์** — ปฏิบัติงานประจำวันตามระเบียบที่คณะกรรมการกำหนด
- **ที่ประชุมใหญ่สามัญประจำปี** — สมาชิกทั้งหมดร่วมอนุมัติงบการเงิน จัดสรรกำไรสุทธิ (เงินปันผล/เงินเฉลี่ยคืน) และเลือกตั้งกรรมการ

### วงจรธุรกิจ

- **รายวัน/รายเดือน**: รับฝาก-ถอนเงิน, อนุมัติและจ่ายเงินกู้, บันทึกรายการหักเงินเดือน ณ ที่จ่ายจากต้นสังกัด, กระทบยอดกับธนาคาร, คำนวณดอกเบี้ยเงินฝาก/เงินกู้รายเดือน
- **รายไตรมาส**: รายงานสถานะการเงินต่อคณะกรรมการ
- **รายปี**: ปิดงบการเงิน, คำนวณเงินปันผล/เงินเฉลี่ยคืน, จัดทำรายงานประจำปีเสนอที่ประชุมใหญ่, ตรวจสอบบัญชีประจำปี

## 1.2 กลุ่มผู้ใช้และ Persona

### ฝั่งเจ้าหน้าที่สหกรณ์ (Back Office)

| Persona | บทบาทหลัก | Pain point ปัจจุบัน |
|---|---|---|
| **เจ้าหน้าที่การเงิน** | บันทึกฝาก-ถอน, กระทบยอดธนาคาร, คำนวณดอกเบี้ย | ทำงานผ่านหลายไฟล์ Excel แยกกัน, กระทบยอด statement ด้วยมือ, เสี่ยงพิมพ์ผิด |
| **เจ้าหน้าที่สินเชื่อ** | รับคำขอกู้, ตรวจเอกสาร/หลักประกัน, จัดทำสัญญาและตารางผ่อนชำระ | ติดตามหนี้ค้างชำระด้วยการนับมือ, ไม่มีระบบแจ้งเตือนอัตโนมัติ |
| **เจ้าหน้าที่ทะเบียนสมาชิก/สวัสดิการ** | ขึ้นทะเบียนสมาชิกใหม่-ลาออก, ดูแลสิทธิสวัสดิการ/เงินสงเคราะห์ | ข้อมูลสมาชิกกระจายอยู่หลายที่ ไม่เชื่อมกับข้อมูลการเงิน |
| **ผู้จัดการ/ผู้บริหาร** | ตัดสินใจเชิงนโยบาย, รายงานต่อคณะกรรมการ | ต้องรอเจ้าหน้าที่รวบรวมข้อมูลก่อนเห็นภาพรวม ไม่มีแดชบอร์ดเรียลไทม์ |
| **ผู้ตรวจสอบกิจการ** | ตรวจสอบความถูกต้องของธุรกรรมและบัญชี | ไม่มี audit trail ที่ตรวจสอบย้อนหลังได้ง่าย |

### ฝั่งสมาชิก (Self-Service)

| Persona | ลักษณะ | Pain point ปัจจุบัน |
|---|---|---|
| **สมาชิกสามัญ (ครูประจำการ)** | ฝากเงินสม่ำเสมอ, ถือหุ้น, อาจมีเงินกู้ | ไม่เห็นยอดเงินฝาก/หุ้น/หนี้คงเหลือแบบเรียลไทม์ ต้องโทรหรือเดินทางมาสอบถามที่สหกรณ์ |
| **สมาชิกสมทบ** | ครอบครัว/บุคลากรที่เกี่ยวข้อง สิทธิบางส่วนต่างจากสมาชิกสามัญ | ไม่แน่ใจสิทธิประโยชน์ของตนเอง |
| **สมาชิกเกษียณ** | ยังคงสถานะสมาชิก แต่ไม่มีเงินเดือนให้หักผ่านต้นสังกัด | ต้องชำระเงินกู้/ค่าหุ้นด้วยวิธีอื่น ต้องการช่องทางแจ้งเตือนและชำระที่สะดวก |

## 1.3 เป้าหมายของระบบ

1. ลดงานซ้ำซ้อนและความผิดพลาดจากการทำงานด้วย Excel/กระดาษของเจ้าหน้าที่
2. ให้สมาชิกเข้าถึงข้อมูลบัญชีของตนเองได้ทันที ลดภาระงานหน้าเคาน์เตอร์
3. ให้ผู้บริหารเห็นภาพรวมการเงินและความเสี่ยง (หนี้ค้างชำระ) แบบเรียลไทม์
4. มี audit trail ที่ตรวจสอบย้อนหลังได้ครบถ้วนตามข้อกำหนดของสหกรณ์
