# เอกสารวิเคราะห์และออกแบบระบบ — แอปบริหารสหกรณ์ออมทรัพย์ครู

ชุดเอกสารนี้เป็นการวิเคราะห์ธุรกิจและออกแบบระบบเบื้องต้นสำหรับ "แอปบริหารจัดการสหกรณ์ออมทรัพย์ครู" (อ้างอิงบริบทสหกรณ์ออมทรัพย์ครูหนองคาย จำกัด) โดยมีเป้าหมายเพื่ออำนวยความสะดวกในการทำงานของเจ้าหน้าที่สหกรณ์ (back office) และการให้บริการตนเองของสมาชิกครู (self-service) ให้มีประสิทธิภาพสูงสุด

เอกสารชุดนี้เป็น**การวิเคราะห์และออกแบบระบบเท่านั้น** ยังไม่มีการพัฒนาโค้ดจริง ใช้เป็นฐานสำหรับการพัฒนาในเฟสถัดไป

## สารบัญ

1. [ภาพรวมธุรกิจและผู้มีส่วนได้ส่วนเสีย](01-ภาพรวมธุรกิจและผู้มีส่วนได้ส่วนเสีย.md) — บริบทการดำเนินงานสหกรณ์ และ persona ของผู้ใช้แต่ละกลุ่ม
2. [โมดูลและฟีเจอร์](02-โมดูลและฟีเจอร์.md) — รายละเอียดฟีเจอร์ทั้งหมด เรียงตามลำดับความสำคัญ
3. [แบบจำลองข้อมูล](03-แบบจำลองข้อมูล.md) — entity หลักและความสัมพันธ์ระดับสูง พร้อม ER diagram
4. [สถาปัตยกรรมระบบและเทคโนโลยี](04-สถาปัตยกรรมระบบและเทคโนโลยี.md) — ทางเลือกช่องทางผู้ใช้ และเทคสแต็กที่แนะนำ
5. [ขอบเขตที่ไม่ใช่ฟังก์ชันและความปลอดภัย](05-ขอบเขตที่ไม่ใช่ฟังก์ชันและความปลอดภัย.md) — PDPA, ความปลอดภัย, การสำรองข้อมูล, audit
6. [แผนงานเป็นระยะ](06-แผนงานเป็นระยะ.md) — MVP และเฟสถัดไป
7. [ข้อสมมติฐานที่ต้องยืนยัน](07-ข้อสมมติฐานที่ต้องยืนยัน.md) — สิ่งที่ต้องตรวจสอบกับสหกรณ์จริงก่อนเริ่มพัฒนา

## ลำดับความสำคัญของโมดูล (สรุป)

| ลำดับ | โมดูล | กลุ่มผู้ใช้หลัก |
|---|---|---|
| 1 | เงินฝาก-หุ้น-เงินกู้ของสมาชิก | เจ้าหน้าที่การเงิน/สินเชื่อ, สมาชิก |
| 2 | สวัสดิการและเงินสงเคราะห์ | เจ้าหน้าที่สวัสดิการ, สมาชิก |
| 3 | รายงานผู้บริหาร/การเงิน | ผู้บริหาร, ผู้ตรวจสอบกิจการ |
| 4 | แจ้งเตือน/สื่อสารกับสมาชิก | เจ้าหน้าที่, สมาชิกทุกคน |
| 5 | นำเข้า/กระทบยอด Statement ธนาคาร | เจ้าหน้าที่การเงิน |
