# 2. โมดูลและฟีเจอร์

เรียงลำดับตามความสำคัญที่กำหนดไว้ แต่ละโมดูลระบุฟีเจอร์ฝั่งเจ้าหน้าที่ (back office) และฝั่งสมาชิก (self-service) แยกกัน

## 2.1 เงินฝาก-หุ้น-เงินกู้ของสมาชิก (โมดูลแกนหลัก)

**เงินฝาก**
- ประเภทบัญชี: ออมทรัพย์, ออมทรัพย์พิเศษ (ดอกเบี้ยสูงกว่า), เงินฝากประจำ (มีกำหนดระยะเวลา)
- ฝาก/ถอน/โอนระหว่างบัญชี, คำนวณดอกเบี้ยอัตโนมัติตามอัตราที่ประกาศ, ออกสมุดคู่ฝากอิเล็กทรอนิกส์/ใบแจ้งยอด

**หุ้น (ทุนเรือนหุ้น)**
- ซื้อหุ้นรายเดือน (มักหักผ่านเงินเดือนพร้อมกับงวดชำระเงินกู้), สะสมมูลค่าหุ้นตลอดอายุสมาชิกภาพ
- คำนวณเงินปันผลตามสัดส่วนหุ้นเมื่อสิ้นปีบัญชี (เชื่อมกับโมดูลรายงาน)

**เงินกู้**
- ประเภทเงินกู้: เงินกู้ฉุกเฉิน (อนุมัติเร็ว วงเงินจำกัด), เงินกู้สามัญ (ใช้ผู้ค้ำประกัน/หุ้นค้ำ), เงินกู้พิเศษ (มีหลักประกัน เช่น ที่ดิน/บ้าน วงเงินสูง ระยะยาว)
- เวิร์กโฟลว์: ยื่นคำขอ → ตรวจสอบคุณสมบัติ/วงเงินสูงสุดตามเงินเดือนคงเหลือ → อนุมัติ (ตามลำดับชั้นวงเงิน) → เบิกจ่าย → สร้างตารางผ่อนชำระ
- คำนวณดอกเบี้ยลดต้นลดดอก, ตารางผ่อนชำระอัตโนมัติ, การชำระก่อนกำหนด/ปิดบัญชีก่อนกำหนด
- การหักเงินเดือน ณ ที่จ่าย: ส่งออกยอดที่ต้องหัก (ค่าหุ้น+เงินฝาก+งวดเงินกู้) ให้ต้นสังกัดทุกเดือน และรับผลการหักจริงกลับมาบันทึก (เชื่อมกับโมดูล 5)

**ฝั่งสมาชิก**: ดูยอดเงินฝาก/หุ้น/เงินกู้คงเหลือแบบเรียลไทม์, ประวัติธุรกรรม, ยื่นคำขอกู้ออนไลน์และติดตามสถานะอนุมัติ, จำลองตารางผ่อนชำระก่อนยื่นกู้

## 2.2 สวัสดิการและเงินสงเคราะห์

- **เงินสงเคราะห์ศพ (ฌกส./ฌส.)**: ทะเบียนสมาชิกกองทุน, เก็บเงินสงเคราะห์รายเดือน/รายกรณี, เวิร์กโฟลว์เบิกจ่ายเมื่อสมาชิกหรือครอบครัวเสียชีวิต
- **ทุนการศึกษาบุตรสมาชิก**: เปิดรับสมัคร-พิจารณา-ประกาศผลประจำปี, ผูกกับเงื่อนไขคุณสมบัติสมาชิก (อายุสมาชิกภาพ, สถานะไม่ค้างชำระ)
- **สวัสดิการรักษาพยาบาล/สงเคราะห์อื่นๆ**: กำหนดเงื่อนไขสิทธิ์ตามระเบียบสหกรณ์ (อายุสมาชิกภาพขั้นต่ำ, ไม่มีหนี้ผิดนัด) ตรวจสอบสิทธิ์อัตโนมัติก่อนอนุมัติจ่าย
- **ฝั่งสมาชิก**: ตรวจสอบสิทธิ์สวัสดิการของตนเอง, ยื่นคำขอรับสวัสดิการออนไลน์พร้อมแนบเอกสาร, ติดตามสถานะการพิจารณา

## 2.3 รายงานผู้บริหาร/การเงิน

- **งบการเงิน**: งบดุล, งบกำไรขาดทุน — สร้างจากธุรกรรมจริงในระบบ ลดงานปิดบัญชีด้วยมือ
- **รายงานหนี้ค้างชำระ**: แยกตามอายุหนี้ (aging), ตามผู้ค้ำประกัน, แจ้งเตือนกรรมการเมื่อมีหนี้เสี่ยงเป็นหนี้สูญ
- **เงินปันผล/เงินเฉลี่ยคืน**: คำนวณจากกำไรสุทธิและสัดส่วนหุ้น/ปริมาณธุรกิจของสมาชิกแต่ละคน พร้อมจำลองสถานการณ์ (what-if) ก่อนเสนอที่ประชุมใหญ่
- **แดชบอร์ดผู้บริหาร**: ภาพรวมสินทรัพย์/หนี้สิน, ยอดเงินฝาก-เงินกู้คงค้าง, จำนวนสมาชิกเปลี่ยนแปลง, KPI ความเสี่ยงหนี้ — อัปเดตแบบเรียลไทม์แทนรอสรุปรายเดือน
- **รายงานสำหรับที่ประชุมใหญ่สามัญประจำปี**: ส่งออกรูปแบบพร้อมนำเสนอ (PDF/Excel) ตามรูปแบบที่นายทะเบียนสหกรณ์กำหนด

## 2.4 แจ้งเตือน/สื่อสารกับสมาชิก

- ช่องทาง: LINE Official Account/LIFF push message เป็นหลัก (เข้าถึงสมาชิกครูไทยได้สูงสุด), รองรับ SMS/อีเมลเป็นช่องทางสำรอง
- แจ้งยอดหักเงินเดือนประจำเดือน (สรุปหุ้น+เงินฝาก+งวดเงินกู้ที่ถูกหักจริง)
- แจ้งเตือนก่อนครบกำหนดชำระ (สมาชิกเกษียณที่ไม่ได้หักผ่านเงินเดือน)
- ประกาศ/ข่าวสารสหกรณ์ (มติที่ประชุม, อัตราดอกเบี้ยใหม่, กำหนดการรับสมัครทุนการศึกษา)
- แจ้งผลการอนุมัติคำขอกู้/คำขอสวัสดิการ

## 2.5 นำเข้า/กระทบยอด Statement

ครอบคลุม 3 แหล่งข้อมูลตามที่ยืนยัน:

1. **ไฟล์หักเงินเดือนจากต้นสังกัด** (เขตพื้นที่การศึกษา/สพฐ./กรมบัญชีกลาง) — นำเข้าไฟล์รายเดือน จับคู่ยอดที่ขอหักกับยอดที่หักจริงต่อสมาชิกแต่ละคน
2. **Statement จากธนาคาร** (เช่น กรุงไทย, ธ.ก.ส.) — นำเข้าและกระทบยอดกับบัญชีเงินฝากสหกรณ์ที่ใช้รับ-จ่ายเงิน
3. **รายการโอนเงินตรงจากสมาชิก** — กรณีสมาชิกโอนชำระเงินกู้/ค่าหุ้นเองผ่านธนาคาร (โดยเฉพาะสมาชิกเกษียณ) จับคู่รายการโอนกับสมาชิกและวัตถุประสงค์การชำระ

**ฟีเจอร์หลัก**: อัปโหลดไฟล์ (CSV/Excel), กฎการจับคู่อัตโนมัติ (เลขสมาชิก/เลขบัญชี/จำนวนเงิน/วันที่), หน้าจอจัดการรายการที่จับคู่ไม่ได้หรือยอดไม่ตรง (ค้างจ่าย/หักไม่ครบ/โอนผิดยอด) ให้เจ้าหน้าที่ตรวจสอบด้วยมือ, บันทึกประวัติการนำเข้าทุกครั้งเพื่อ audit

## 2.6 โมดูลสนับสนุน

- **ทะเบียนสมาชิก**: ข้อมูลส่วนบุคคล, สถานะสมาชิกภาพ (สามัญ/สมทบ/เกษียณ/ลาออก), ต้นสังกัด, ผู้รับผลประโยชน์
- **ยืนยันตัวตน/สิทธิ์การเข้าถึง (RBAC)**: แยกสิทธิ์ตามบทบาท (การเงิน/สินเชื่อ/ทะเบียน/ผู้บริหาร/ผู้ตรวจสอบ) และสิทธิ์อนุมัติตามวงเงิน, ฝั่งสมาชิกยืนยันตัวตนผ่าน LINE Login/เลขสมาชิก+OTP
- **Audit trail**: บันทึกทุกการสร้าง/แก้ไข/ลบธุรกรรมทางการเงิน พร้อมผู้กระทำและเวลา ตรวจสอบย้อนหลังได้สำหรับผู้ตรวจสอบกิจการ
