# เครื่องมือตรวจสอบสถานะบุคคลล้มละลาย (กรมบังคับคดี) แบบกลุ่ม

สคริปต์นี้อ่านรายชื่อ/เลขบัตรประชาชนจากไฟล์ Excel แล้วกรอกฟอร์ม "สอบถามบุคคลล้มละลาย"
บนเว็บไซต์กรมบังคับคดี (`ledwebsite.led.go.th`) ให้อัตโนมัติทีละคน

เนื่องจากฟอร์มค้นหามี CAPTCHA ป้องกันบอท สคริปต์จึง **ไม่ได้พยายามถอดรหัส CAPTCHA เอง**
แต่จะเปิดเบราว์เซอร์จริงให้เห็น แล้วหยุดรอให้ผู้ใช้พิมพ์รหัสที่เห็นในภาพทีละรอบ
ส่วนที่เหลือ (ล็อกอิน session ค้าง, กรอกฟอร์ม, กดค้นหา, อ่านผลลัพธ์, บันทึกไฟล์) ทำอัตโนมัติทั้งหมด

## ติดตั้ง

```bash
pip install -r requirements.txt
playwright install chromium
```

## รัน

```bash
python bulk_check.py --input CardID.xlsx --sheet 0769 --output results.xlsx
```

**แนะนำให้ทดสอบก่อนด้วยจำนวนน้อยๆ**:

```bash
python bulk_check.py --input CardID.xlsx --sheet 0769 --output results_test.xlsx --limit 5
```

ตรวจสอบว่าผลลัพธ์ในไฟล์ `results_test.xlsx` ตรงกับที่เห็นในเบราว์เซอร์จริง ก่อนรันเต็มจำนวน 7,337 รายชื่อ

## ระหว่างรัน

1. เบราว์เซอร์จะเปิดขึ้นมาที่หน้าเว็บกรมบังคับคดี — **ล็อกอินด้วยตัวเองในเบราว์เซอร์นั้น**
   (ไม่ว่าจะล็อกอินด้วยวิธีไหนก็ตาม สคริปต์ไม่ยุ่งกับขั้นตอนนี้)
2. ล็อกอินเสร็จแล้ว กลับมาที่หน้าต่าง terminal แล้วกด Enter
3. สำหรับแต่ละรายชื่อ สคริปต์จะกรอกเลขบัตรประชาชนให้ แล้วหยุดถามรหัส CAPTCHA
   - ดูรหัสได้จากหน้าต่างเบราว์เซอร์ หรือเปิดไฟล์ `captcha.png` ที่บันทึกไว้ในโฟลเดอร์เดียวกัน
   - พิมพ์ `r` แล้ว Enter เพื่อขอรหัสใหม่ถ้าอ่านไม่ออก
   - พิมพ์ `s` แล้ว Enter เพื่อข้ามรายนี้ (จะบันทึกเป็น "ตรวจสอบไม่สำเร็จ")
4. ผลลัพธ์จะถูกบันทึกลงไฟล์ output ทันทีหลังตรวจแต่ละราย

## หยุดกลางคันและรันต่อ

กด `Ctrl+C` เพื่อหยุดได้ทุกเมื่อ — ผลลัพธ์ที่ตรวจไปแล้วถูกบันทึกไว้แล้ว
รันคำสั่งเดิมซ้ำได้เลย สคริปต์จะข้ามรายชื่อที่มีอยู่แล้วในไฟล์ output โดยอัตโนมัติ

## รูปแบบไฟล์ input ที่รองรับ (ค่า default)

| คอลัมน์ | ตำแหน่ง | ความหมาย |
|---|---|---|
| A | index 0 | เลขบัตรประชาชน 13 หลัก |
| B | index 1 | เลขทะเบียนสมาชิก |
| C | index 2 | ชื่อ-นามสกุล |

ถ้าไฟล์ของคุณเรียงคอลัมน์ต่างไป ปรับได้ด้วย `--id-col`, `--member-col`, `--name-col`

## ไฟล์ output

คอลัมน์: เลขทะเบียนสมาชิก, เลขบัตรประชาชน, ชื่อ-นามสกุล (จากไฟล์), สถานะคดี
(ไม่พบคดี / พบคดี / ตรวจสอบไม่สำเร็จ), รายละเอียดคดีที่พบ, เวลาที่ตรวจสอบ

## ข้อควรทราบ

- สคริปต์นี้เขียนจาก HTML จริงของหน้าฟอร์ม `WEB3Q010` (สอบถามบุคคลล้มละลาย) ที่ได้รับมา
  แต่ยังไม่เคยรันกับระบบจริง จุดที่อาจต้องปรับแก้หลังทดสอบจริง:
  - การอ่านผลลัพธ์จากตาราง (`parse_results_table` ใน `bulk_check.py`) — โดยเฉพาะกรณี
    "ไม่พบคดี" ที่หน้าเว็บอาจแสดงผลต่างจากที่คาดไว้
  - ข้อความ error ที่ตรวจจับตอน CAPTCHA ผิด (`page_has_error_text`) — ถ้าเว็บแสดงข้อความ
    ต่างจากที่ระบุไว้ ให้เพิ่มข้อความนั้นเข้าไปในลิสต์ `marker`
- ใช้บัญชีของตัวเอง (บุคคลทั่วไป) ตามที่ได้แจ้งไว้ — โปรดตรวจสอบว่าปริมาณการค้นหา
  (7,000+ รายการ) เป็นไปตามเงื่อนไขการใช้งานของระบบ ก่อนรันเต็มจำนวน
