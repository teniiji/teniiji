# เครื่องมือตรวจสอบสถานะบุคคลล้มละลาย (กรมบังคับคดี) แบบกลุ่ม

สคริปต์นี้อ่านรายชื่อ/เลขบัตรประชาชนจากไฟล์ Excel แล้วกรอกเลขบัตรในฟอร์ม
"สอบถามบุคคลล้มละลาย" บนเว็บไซต์กรมบังคับคดี (`ledwebsite.led.go.th`) ให้อัตโนมัติทีละคน

เนื่องจากฟอร์มค้นหามี CAPTCHA ป้องกันบอท และจากการทดสอบจริงพบว่า **เว็บไซต์จะล้าง
ค่าช่อง CAPTCHA ทิ้งถ้าเป็นการกรอกด้วยสคริปต์** (ตรวจจับได้ว่าไม่ใช่คนพิมพ์จริง)
สคริปต์นี้จึง **ไม่แตะช่อง CAPTCHA เลย** — ผู้ใช้ต้องพิมพ์รหัส CAPTCHA และกดปุ่ม
"ค้นหา" เองในเบราว์เซอร์จริงทุกครั้ง ส่วนที่เหลือ (ล็อกอิน session ค้าง, กรอกเลขบัตร,
อ่านผลลัพธ์, บันทึกไฟล์, ไปรายชื่อถัดไป) ทำให้อัตโนมัติทั้งหมด

## ติดตั้ง

```bash
pip install -r requirements.txt
playwright install chromium
```

## รัน

```bash
python bulk_check.py --input CardID.xlsx --sheet 0769 --output results.xlsx
```

**แนะนำให้ทดสอบก่อนด้วยจำนวนน้อยๆ**:

```bash
python bulk_check.py --input CardID.xlsx --sheet 0769 --output results_test.xlsx --limit 5
```

ตรวจสอบว่าผลลัพธ์ในไฟล์ `results_test.xlsx` ตรงกับที่เห็นในเบราว์เซอร์จริง ก่อนรันเต็มจำนวน 7,337 รายชื่อ

## ระหว่างรัน

1. เบราว์เซอร์เปล่าจะเปิดขึ้นมา — **นำทาง/ล็อกอินด้วยตัวเองตามปกติ** (พิมพ์ URL,
   ล็อกอิน, คลิกเมนู) จนกว่าจะเปิดหน้า **"สอบถามบุคคลล้มละลาย"** (WEB3Q010) ได้สำเร็จ
   1 ครั้ง (สคริปต์ไม่ยุ่งกับขั้นตอนนี้ ทำเหมือนที่คุณเคยทำได้เลย)
2. เปิดหน้านั้นสำเร็จแล้ว กลับมาที่หน้าต่าง terminal แล้วกด Enter
3. สำหรับแต่ละรายชื่อ สคริปต์จะกรอกเลขบัตรประชาชนในหน้าเว็บให้เอง แล้วรอ
   - ไปที่เบราว์เซอร์ **พิมพ์รหัส CAPTCHA เอง** แล้ว**กดปุ่ม "ค้นหา" เอง**
   - ถ้าพิมพ์ CAPTCHA ผิด เว็บจะแจ้งเตือน "รหัสภาพไม่ถูกต้อง" กด OK แล้วพิมพ์ใหม่
     กดค้นหาอีกครั้งได้เลยในหน้าเดิม ไม่ต้องกลับมาที่ terminal จนกว่าจะเห็นผลลัพธ์จริง
   - เห็นผลลัพธ์ขึ้นในตาราง "รายการที่ค้นพบ" แล้ว ค่อยกลับมาที่ terminal กด Enter
     (หรือพิมพ์ `s` แล้ว Enter ถ้าต้องการข้ามรายนี้)
4. ผลลัพธ์จะถูกบันทึกลงไฟล์ output ทันทีหลังตรวจแต่ละราย แล้วสคริปต์จะพาไปหน้าค้นหา
   ว่างสำหรับรายชื่อถัดไปให้เอง (กรอกเลขบัตรใหม่ให้อัตโนมัติ)

## หยุดกลางคันและรันต่อ

กด `Ctrl+C` เพื่อหยุดได้ทุกเมื่อ — ผลลัพธ์ที่ตรวจไปแล้วถูกบันทึกไว้แล้ว
รันคำสั่งเดิมซ้ำได้เลย สคริปต์จะข้ามรายชื่อที่มีอยู่แล้วในไฟล์ output โดยอัตโนมัติ

## รูปแบบไฟล์ input ที่รองรับ (ค่า default)

| คอลัมน์ | ตำแหน่ง | ความหมาย |
|---|---|---|
| A | index 0 | เลขบัตรประชาชน 13 หลัก |
| B | index 1 | เลขทะเบียนสมาชิก |
| C | index 2 | ชื่อ-นามสกุล |

ถ้าไฟล์ของคุณเรียงคอลัมน์ต่างไป ปรับได้ด้วย `--id-col`, `--member-col`, `--name-col`

## ไฟล์ output

คอลัมน์: เลขทะเบียนสมาชิก, เลขบัตรประชาชน, ชื่อ-นามสกุล (จากไฟล์), สถานะคดี
(ไม่พบคดี / พบคดี / ตรวจสอบไม่สำเร็จ), รายละเอียดคดีที่พบ, เวลาที่ตรวจสอบ

สถานะ "ตรวจสอบไม่สำเร็จ" หมายถึงกดค้นหาแล้วแต่สคริปต์ไม่พบทั้งข้อความ
"ไม่พบรายการที่ค้นหา" และไม่พบแถวข้อมูลจริงในตาราง (เช่น เผลอกด Enter ก่อนที่
CAPTCHA จะผ่าน) — รายเหล่านี้ควรกลับไปตรวจสอบซ้ำด้วยตนเอง

## ข้อควรทราบ

- สคริปต์นี้เขียนจาก HTML จริงของหน้าฟอร์ม `WEB3Q010` (สอบถามบุคคลล้มละลาย) และ
  ข้อความ "ไม่พบรายการที่ค้นหา" / "รหัสภาพไม่ถูกต้อง" ที่ยืนยันจากการทดสอบจริงแล้ว
  แต่ยังทดสอบกับจำนวนน้อยๆ (`--limit 5`) ก่อนรันเต็มจำนวนเสมอ
- ใช้บัญชีของตัวเอง (บุคคลทั่วไป) ตามที่ได้แจ้งไว้ — โปรดตรวจสอบว่าปริมาณการค้นหา
  (7,000+ รายการ) เป็นไปตามเงื่อนไขการใช้งานของระบบ ก่อนรันเต็มจำนวน
